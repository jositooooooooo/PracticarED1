## 📝 Notas de aprendizaje

### Polinomios

En esta unidad aprendí a representar un problema utilizando clases y a organizar el proyecto utilizando el patrón **MVC (Model-View-Controller)**.

La estructura permite separar:

* **Model:** datos y lógica del programa.
* **View:** interacción y presentación al usuario.
* **Controller:** comunicación entre Model y View.
