# 📐 Polinomios

Implementación de una clase `Polinomio` desarrollada como práctica para la materia **Estructuras de Datos 1 — INF-220**.

## 🎯 Objetivo

Desarrollar una estructura para representar y trabajar con polinomios utilizando Python.

## 🏗️ Arquitectura

El proyecto está organizado utilizando el patrón **MVC**.

```text
POLINOMIOS/
│
├── controllers/
│   └── controller.py
│
├── models/
│   └── model.py
│
├── views/
│   └── view.py
│
├── main.py
└── README.md
```

### Model

Contiene la lógica y los datos relacionados con el polinomio.

### View

Se encarga de la interacción y presentación al usuario.

### Controller

Coordina la comunicación entre el Model y la View.
